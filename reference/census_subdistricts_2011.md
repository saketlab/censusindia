# Subdistrict directory (2011)

Subdistrict (tehsil/taluka) population from the 2011 Census.

## Usage

``` r
data(census_subdistricts_2011)
```

## Format

A tibble with 7,074 rows and 15 columns:

- year:

  Census year for population data (2011)

- geography:

  Geographic level ("subdistrict")

- state:

  Name of the state

- state_name_harmonized:

  Harmonized state name for joining across datasets

- district:

  Name of the district

- subdistrict:

  Name of the subdistrict (tehsil/taluka)

- population:

  Total population

- males:

  Male population

- females:

  Female population

- households:

  Number of households

- inhabited_villages:

  Number of inhabited villages

- uninhabited_villages:

  Number of uninhabited villages

- towns:

  Number of towns

- area_km2:

  Area in square kilometers

- density:

  Population density per square kilometer
