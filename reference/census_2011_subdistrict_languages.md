# Census 2011 subdistrict languages (C-16)

Mother tongue speakers by language at subdistrict level from the 2011
Census C-16 tables, with male/female and rural/urban breakdowns.

## Usage

``` r
data(census_2011_subdistrict_languages)
```

## Format

A tibble with 183,127 rows and 11 columns:

- state_code:

  Numeric state code

- state_name_harmonized:

  Harmonized state name for joining across datasets

- district_code:

  Numeric district code

- area_name:

  Name of the subdistrict

- language_name:

  Name of the language

- language_group:

  Numeric language group code

- total_speakers:

  Total speakers

- male_speakers:

  Male speakers

- female_speakers:

  Female speakers

- rural_speakers:

  Rural speakers

- urban_speakers:

  Urban speakers

## Source

Census of India 2011, C-16 Mother Tongue Tables.
